# استودیو مای‌بات (MyBot Studio)

ابزار بصری و خودمیزبان ساخت ربات تلگرام با بوم ReactFlow، بک‌اند FastAPI و موتور Aiogram.

[English](README.md) · [فارسی](README.fa.md) · [العربية](docs/README.ar.md) · [Русский](docs/README.ru.md)

> **v0.3-BETA پیشانتشار است، نه نسخه پایدار.** از شاخهٔ پیشفرض `master` کلون کنید. پیش از آزمایش از دادههای قبلی پشتیبان بگیرید.

## تغییرات v0.3

این نسخه یک **لایهٔ ایمنی و صحت** روی مجموعهٔ امکانات v0.2 است. رفتار بوم، کیبورد و شبیهساز تغییر نکرده؛ آنچه عوض شده نحوهٔ احراز هویت، محلیسازی و اعتبارسنجی API پنل است.

- **احراز هویت default-deny:** همهٔ مسیرهای `/api` بهجز health/login/webhook/media و مسیرهای خواندن i18n حالا توکن `Bearer` صادرشده توسط همین بکاند میخواهند؛ میدلویر پیش از اجرای کد مسیر و `require_admin` روی هر روتروتر محافظت را اعمال میکنند.
- **پیکربندی fail-closed:** `config.py` دیگر `JWT_SECRET` حدسی یا `DEFAULT_ADMIN_PASS` آماده ندارد؛ کلید امضای خالی راهاندازی را متوقف میکند و نصابها کلید منحصربهفرد برای هر نصب میسازند.
- **پاسخهای محلیشدهٔ API:** همهٔ متون قابل رؤیت API از `backend/locales/<code>.json` (`en`، `fa`، `ar`، `ru`) با تکیه به `Accept-Language` خوانده می‌شوند و متن استثناهای پایتون دیگر به مرورگر نمیرسد.
- **اعتبارسنجی وارد کردن فلو:** `POST /api/flows/{bot}/import` پیش از نوشتن، نوع نامعتبر نود، لبهٔ معلق/تکراری، نبود trigger و `callback_data` بلندتر از حد تلگرام را با ۴۲۲ رد میکند؛ قالب ردمشده، گراف ذخیرهشده را دستنخورده میگذارد.
- **ایمنسازی SSRF و آپلود:** آدرسهای خروجی از گارد IP خصوصی/loopback عبور میکنند و آپلود زبان/قلم نام مشتقشده را اعتبارسنجی و از فرار از پوشهٔ مقصد جلوگیری میکند.
- **زیرساخت تست و CI:** تست‌های جدید بکاند، `pytest.ini`، `requirements-dev.txt`، `conftest.py` برای پیکربندی fail-closed و کارافلو CI که گارد لوکال، تست بکاند، ممیزی فرانتاند و build Vite را در هر push/PR اجرا میکند. جزئیات: [یادداشت انتشار](docs/releases/v0.3.md).

## محدودیت کیبورد تلگرام

هر ارسال فقط **یک `reply_markup`** دارد؛ کیبورد شیشه‌ای و معمولی در یک درخواست ترکیب نمی‌شوند. کیبورد معمولی قبلی ممکن است زیر پیام بعدی دارای دکمه شیشه‌ای باقی بماند، اما این به معنای ارسال هر دو با همان پیام نیست. نود کیبورد به پیام پیشین اجراشده در مسیر خودش متصل می‌شود، نه پیام شاخه‌ای دیگر.

**ویرایش پیام فقط کیبورد شیشه‌ای را می‌پذیرد.** کیبورد معمولی با متدهای ویرایش تلگرام قابل اتصال نیست. ویرایش متن، کپشن رسانه و فقط دکمه‌ها متدهای متفاوت دارند؛ ویرایش صرفاً دکمه نباید متن خالی ارسال کند. شبیه‌ساز محلی، اثبات تحویل موفق در تلگرام نیست.

## نصب

### دریافت سورس پیشانتشار

Git را نصب کنید و شاخهٔ پیشفرض `master` را کلون کنید:

```bash
git clone --branch master https://github.com/mybot-studio/mybot-studio.git
cd mybot-studio
```

### اجرای محلی بدون Docker

از **ریشه مخزن** اجرا کنید، نه پوشه `backend/` یا `frontend/`:

**Windows (CMD / PowerShell)**
```bat
.\start-local.bat
```

**Linux / macOS**
```bash
bash start-local.sh
```

پیش‌نیازها: Python **3.10+** همراه `pip` و `venv`، و Node.js **18+** همراه npm (نیاز Vite 5). نسخه LTS تحت پشتیبانی Node پیشنهاد می‌شود. ابزارها باید در PATH باشند. `uv` اختیاری است و در نبود آن pip استفاده می‌شود. دریافت وابستگی‌ها اینترنت می‌خواهد؛ ربات واقعی نیز به ارتباط با تلگرام نیاز دارد. خودمیزبان بودن به معنی کارکرد آفلاین تلگرام نیست.

هر دو فایل، **`start-local.py`** را فراخوانی می‌کنند. این برنامه در صورت نبود `.env` آن را می‌سازد، محیط `backend/.venv` و وابستگی‌های پایتون را آماده می‌کند، import بک‌اند را بررسی می‌کند و در نبود `node_modules` وابستگی‌های فرانت‌اند را نصب می‌کند. اجرای معمول، API را راه می‌اندازد، منتظر پاسخ آن در `127.0.0.1:23567` می‌ماند و بعد Vite را اجرا می‌کند (معمولاً `http://localhost:23568`).

فقط بررسی وابستگی‌ها و import:

```bat
.\start-local.bat --check
```
```bash
bash start-local.sh --check
```

**`--check` نه worker، نه API و نه فرانت‌اند را اجرا می‌کند و سلامت سرویس را اثبات نمی‌کند.** این گزینه می‌تواند فایل تنظیمات و محیط مجازی بسازد، وابستگی نصب کند و کد بک‌اند را import کند؛ فقط‌خواندنی نیست. وجود `node_modules` نیز به معنی بررسی کامل نسخه وابستگی‌ها توسط لانچر نیست.

### VPS لینوکس / Docker

از کلون کامل بالا استفاده کنید، `install.sh` را بخوانید و از ریشه اجرا کنید:

```bash
sudo bash install.sh
```

نصاب به فایل‌های کناری در `deploy/` و `backend/` نیاز دارد؛ اسکریپت دانلودشده را به‌تنهایی با pipe از curl اجرا نکنید. نصاب تنظیمات اتصال، ادمین و پراکسی اختیاری را می‌پرسد و سرویس‌های Docker را می‌سازد. پرسش دامنه/SSL به‌تنهایی **گواهی صادر نمی‌کند**؛ HTTPS را جداگانه تنظیم و بررسی کنید. در ویندوز دارای Docker/Compose، `install.bat` را بررسی و اجرا کنید؛ برای توسعه محلی معمول از `start-local.bat` استفاده کنید.

این پیش‌انتشار برای استقرار عمومی ایمن‌سازی نهایی نشده است. رمز پیش‌فرض و کلید امضا را عوض کنید، تنظیمات مؤثر را بررسی کنید، دسترسی پنل را محدود کنید و از `.env`، دیتابیس‌ها و آپلودها پشتیبان بگیرید. توکن ربات، رمز و لاگ خصوصی را منتشر نکنید. جدا بودن کانتینر worker تضمین «بدون قطعی» نیست؛ تغییر موتور به به‌روزرسانی worker نیز نیاز دارد. [یادداشت انتشار](docs/releases/v0.3.md) را ببینید.

## کار با استودیو

۱. با توکن خودتان از BotFather ربات اضافه کنید و وارد Studio شوید.
۲. تریگر را به Send Message و سپس Keyboard متصل کنید. بعد از Edit Message فقط حالت inline را انتخاب کنید.
۳. متن و کیبورد را ویرایش و ذخیره کنید؛ فرمان و callback را در شبیه‌ساز امتحان کنید و تحویل واقعی را جداگانه با ربات آزمایشی بررسی کنید.
۴. پیش از استفاده از نودهای محدودشده متغیر/دیتابیس، ذخیره متغیر کاربر را در تنظیمات ربات فعال کنید.

| کار | میان‌بر |
| --- | --- |
| بازگردانی تغییر گراف | Ctrl+Z |
| انجام دوباره | Ctrl+Shift+Z / Ctrl+Y |
| ذخیره اسنپ‌شات فلو | Ctrl+S / Ctrl+Shift+S |

در macOS معادل Cmd نیز پشتیبانی می‌شود. فیلدهای ویرایش گراف از تاریخچه گراف استفاده می‌کنند؛ فیلدهای تنظیمات نامرتبط و متن شبیه‌ساز undo بومی دارند. هشدار خروج به رفتار مرورگر وابسته است و ذخیره خودکار نیست.

## معماری، زبان‌ها و افزونه‌ها

```text
React / Vite / ReactFlow
          | REST API
       FastAPI panel
          | SQLite / flow data
       Aiogram worker
          | network
       Telegram Bot API
```

هر ربات ذخیره SQLite جدا (`bot_{id}.db`) دارد. متغیرهای JSON به سرور دیتابیس جدا نیاز ندارند. در Docker پنل و worker سرویس‌های جدا هستند. تنظیم پراکسی می‌تواند در شبکه محدود کمک کند، اما تضمین اتصال دائمی نیست.

فایل‌های زبان انگلیسی، فارسی، عربی و روسی برای پنل در `frontend/src/locales/` و برای پیام‌های API و ربات در `backend/locales/` قرار دارند. پیش‌نمایش شناور حالت ویرایش، شبیه‌ساز و کوچک‌سازی/بازگردانی دارد؛ ظاهر آن تقریبی است. پنل نیز بخش‌های پروفایل ربات‌ها، افزونه‌ها و تنظیمات دارد.

[دایرکتوری پلاگینهای مایبات](https://github.com/mybot-studio/mybot-plugins) برای افزونهها و تمپلیتهای جامعه کاربری است. پیش از نصب، کد و دسترسی افزونه را بررسی کنید.

## مشارکت و لایسنس

پیش از پیشنهاد قابلیت، Issue همراه مراحل بازتولید و لاگ بدون اطلاعات محرمانه ثبت کنید. اگر هوش مصنوعی روی این مخزن کار میکند، قوانین [`AGENTS.md`](AGENTS.md) را دنبال کند؛ `scripts/check_i18n.py` مرجع قرارداد زبان است و `AGENTS.md` فقط آن را اسناد میکند. GitHub Actions همان بررسیهای زیر را اجرا میکند؛ نتیجه واقعی را گزارش کنید، نه تعداد قبولیِ فرضی. build سالم یا بررسی وابستگی، آزمون مرورگر و تحویل تلگرام را تأیید نمیکند.

```bash
pip install -r backend/requirements.txt -r backend/requirements-dev.txt
python scripts/check_i18n.py --scan   # برابری کلیدهای زبان و نبود رشته فارسی/انگلیسی در کد
cd backend && python -m pytest -q    # گارد احراز هویت، قرارداد زبان، اعتبارسنجی وارد کردن فلو
cd frontend && npm ci && npm test    # ذخیره توکن، سرصفحه زبان، ممیزی لوکال
cd frontend && npm run build
```

دو قاعده برای هر تغییر در API الزامی است:

- هر متنی که کاربر می‌بیند کلیدی در فضای نام `api` داخل `backend/locales/<code>.json` است و با `t(key, language_from_request(request), ...)` برگردانده می‌شود. `scripts/check_i18n.py --scan` روی رشته انگلیسی هاردکدشده، کلید غایب در هر چهار زبان، یا `{placeholder}` ناهمسان خطا می‌دهد.
- هر مسیر `/api` به‌جز `/api/health` و `/api/auth/login` به توکن `Bearer` صادرشده توسط همین بک‌اند نیاز دارد؛ میدل‌ویر محافظ پیش از اجرای کد مسیر آن را بررسی می‌کند، پس مسیر جدید به‌صورت پیش‌فرض محافظت‌شده است. `ADMIN_SECRET_PATH` فقط نام حسابی است که فرم ورود می‌پذیرد و هرگز در پاسخ API یا مرورگر ظاهر نمی‌شود.
